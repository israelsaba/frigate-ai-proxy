# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository, please **do not** open a public issue.

Instead, please send an encrypted or direct email to `israelsaba@gmail.com` with:
- Description of the vulnerability.
- Steps to reproduce.
- Potential impact.

You will receive an initial response within 48 hours with remediation steps.
